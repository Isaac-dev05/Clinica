Sobre este projeto

A Clínica Bem-Estar é um site fictício desenvolvido exclusivamente para fins de estudo de HTML, CSS e JavaScript.

O projeto explora interfaces responsivas, acessibilidade, busca de serviços e simulação de consultas. Imagens, serviços, valores e contatos são ilustrativos.

Este site não representa uma clínica real, não oferece atendimento médico e não realiza agendamentos. O formulário de contato não envia mensagens.
